# SearchDH

A web application that allows users to paste product URLs from various e-commerce sites and find similar products on DHgate.

## Features

- Paste any product URL to search for DHgate alternatives
- Extracts product information from HTML content
- Special handling for Nike and other popular brand URLs
- Mobile-responsive design
- Clean, modern UI

## Development

This project uses HTML, CSS, and JavaScript with Google Custom Search API integration.

### Setup

1. Clone this repository
2. Open `GoogleSearch.html` in your browser
3. Start searching!

## Deployment

This project is deployed on Netlify.
